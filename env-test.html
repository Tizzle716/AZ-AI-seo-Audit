Environment Variables in Vite

The Problem: process is not defined

When migrating from Create React App to Vite, you might encounter this error when trying to access environment variables:

ReferenceError: process is not defined

This happens because Create React App uses:

const apiUrl = process.env.REACT_APP_API_BASE_URL;

While Vite uses a different approach.

The Solution: import.meta.env

Vite exposes environment variables through the import.meta.env object:

const apiUrl = import.meta.env.VITE_API_BASE_URL;

And environment variables must be prefixed with VITE_ instead of REACT_APP_:

.env file:

VITE_API_BASE_URL=https://api.example.com
VITE_APP_VERSION=1.0.0

Implementation Changes

We've updated the following files to fix the issue:

  1. AuthContext.jsx - Changed process.env.REACT_APP_API_BASE_URL to import.meta.env.VITE_API_BASE_URL
  2. .env - Updated prefixes from REACT_APP_* to VITE_* and added VITE_APP_VERSION
  3. .env.local - Added development-specific variables with the VITE_ prefix
